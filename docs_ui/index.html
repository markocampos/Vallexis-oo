User and Developer Guides

Introduction

Welcome to the Vallexis documentation site. This documentation covers API usage, frontend setup, and general guides for the Automated Digital Rights Management (DRM) and Asset Delivery API.

Authentication

All API requests must be authenticated. We use API keys for authentication. Include your API key in the Authorization header of your requests.

Authorization: Bearer YOUR_API_KEY

API Endpoints

The Vallexis API provides several endpoints for managing products, claims, and DRM operations.

Claims

  • POST /api/claims - Submit a new claim for an asset.
  • GET /api/claims/{claim_id} - Retrieve the status of a specific claim.

Health

  • GET /health - Check the health status of the API.

Webhooks

Webhooks allow your application to receive real-time notifications about events in your Vallexis account, such as successful asset deliveries or failed processing attempts.

To configure webhooks, navigate to the Webhooks section in your seller dashboard and provide a valid URL to receive POST requests.
